## About Me

I am a **Senior AI-Driven Software Development Engineer in Test** with **7+ years** of experience in Software Quality Assurance (SQA) and Test Automation. I combine solid engineering fundamentals with modern AI to test faster, smarter, and more reliably.

My expertise includes **AI-powered Manual Testing, Automation Testing, API Testing, Performance Testing, and Security Testing**.

I have worked across diverse domains: **HR & Payroll, Financial Software, Medical Management, eCommerce, CRM, and Ticket Booking Systems**. I am passionate about using AI, modern testing tools, and intelligent automation to improve software quality, optimize testing processes, and deliver reliable, secure, and scalable solutions.

## AI-Driven Testing Skills

| Skill | What I do |
| ----- | --------- |
| **AI Test Case Generation** | Turn requirements, user stories, and Figma/UI flows into complete test cases, edge cases, and negative scenarios using LLMs |
| **AI-Assisted Bug Reporting** | Produce clear, reproducible bug reports with title, steps, expected/actual results, and severity from screenshots and logs |
| **AI-Powered Test Automation** | Generate and maintain Playwright, Selenium, and Appium scripts with AI, then review and commit them as real code |
| **Self-Healing Locators** | Reduce flaky tests by using AI-assisted locator recovery and stable selector strategies |
| **AI Browser Agents** | Use agent frameworks and MCP browser tools for exploratory testing and page/flow discovery |
| **Prompt Engineering for QA** | Write structured prompts with context, examples, and output formats to get reliable QA output from LLMs |
| **AI-Assisted API Testing** | Generate API test suites, payload variations, and validation checks from specs and live responses |
| **AI for Test Data** | Create realistic, safe, and varied test data for functional, boundary, and negative testing |
| **AI-Assisted Failure Analysis** | Triage failed runs faster by summarizing logs, stack traces, and Allure reports |
| **LLM / AI Application Testing** | Evaluate AI features for accuracy, hallucination, bias, prompt injection, and consistency |
| **AI in CI/CD** | Integrate automated test runs and AI-generated summaries into pipelines |
